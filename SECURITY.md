# Security Policy

## Supported Versions

Only the latest official release of Dopamine is actively maintained and supported with security updates. Older versions may not receive security patches.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅        |
| Older   | ❌        |

## Reporting a Vulnerability

If you discover a security vulnerability in Dopamine, **please do not report it publicly via GitHub issues**.

Instead, report it responsibly by emailing:

**🔐 opa334: opa334@protonmail.com**

Please include the following in your report:

- A detailed description of the vulnerability
- Steps to reproduce the issue
- Impact assessment (e.g., remote code execution, privilege escalation)
- Any suggested fix or mitigation (optional)

We appreciate your responsible disclosure and will do our best to respond promptly. All reports will be reviewed and acknowledged within 7 days, and a patch will be issued as quickly as possible depending on severity.

## Scope

This security policy covers:

- The Dopamine jailbreak app and its source code
- Scripts and dependencies contained within this repository
- Interaction with the jailbroken system as enabled/configured by Dopamine

**Out of scope:**

- Security issues in unrelated jailbreak tweaks or third-party packages
- Vulnerabilities in the iOS kernel or hardware (please report those to Apple)

## Coordinated Disclosure

We strongly prefer **coordinated disclosure** and will work with you to responsibly address any valid security concerns. You may be credited in the changelog or advisory if you wish, or remain anonymous.

Thank you for helping improve the security of Dopamine!
